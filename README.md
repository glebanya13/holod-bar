# 🍹 Bar Menu
The Bar Menu is a web application designed to provide a simple, image-based menu for a lounge bar. The project's primary purpose is to display a series of images representing different menu categories, such as teas, lemonades, and snacks, in a scrollable format. The core features of this project include a user-friendly interface, optimized image loading, and accessibility for users with visual impairments.

## 🚀 Key Features
- **Image-based menu**: The application displays a series of images representing different menu categories.
- **Scrollable format**: Users can scroll through different menu categories.
- **Optimized image loading**: The application uses `webp` image format and `loading="lazy"` attribute to optimize image loading times.
- **Accessibility**: The application includes `alt` attributes for each image to ensure accessibility for users with visual impairments.

## 🛠️ Tech Stack
- **Frontend**: HTML, CSS
- **Image format**: WebP
- **Attributes**: `decoding="async"`, `loading="lazy"`
- **External stylesheet**: `styles.css`
- **Image directory**: `assets/slides`

## 📦 Getting Started / Setup Instructions
### Prerequisites
- A web browser
- A code editor or IDE

### Installation
1. Clone the repository to your local machine.
2. Open the `index.html` file in a web browser.

### Running locally
1. Make sure all the image files are located in the `assets/slides` directory.
2. Open the `index.html` file in a web browser to view the menu.
